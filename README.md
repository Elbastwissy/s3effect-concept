# S3EFFECT — design concept

A proposed redesign for [S3EFFECT](https://s3effect.com), the Egyptian sports-supplement store. **This is a design concept, not the official site.**

- English by default, Arabic (RTL) toggle
- Story-reel hero, kinetic type, product cutouts, ticker tapes
- Stack builder (4 questions → 3 in-stock products)
- S3 Coach chat (AI when opened inside Claude; a rule-based fallback elsewhere)
- Cart hands off to S3's official Shopify checkout

Products, prices and photos come from s3effect.com as listed on 19 Nov 2026.
